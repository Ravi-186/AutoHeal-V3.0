## 1. The RCA Integrity Problem

In enterprise security operations, automated diagnostics and AI assistants frequently blur the boundary between empirical facts and speculative interpretations. When an AI model hallucinates or treats a statistical probability as a ground-truth certainty, security engineers make catastrophic remediation decisions—such as blocking critical partner networks or invalidating executive credentials.

AutoHeal v3.0 enforces strict tripartite separation in its Root-Cause Analysis (RCA) engine:

```
+-------------------------------------------------------------------------+
|                  ROOT-CAUSE ANALYSIS TRIPARTITE MODEL                   |
+-------------------------------------------------------------------------+
|  [CONFIRMED FACTS]       |  [PROBABLE CAUSES]      |  [AI HYPOTHESES]   |
|  Evidence-Proven Only    |  Rule-Supported Detections | Speculative Explanations|
|  - Source IP             |  - Credential Stuffing  | - External credential  |
|  - Request Count         |  - Unescaped SQL        |   dump testing         |
|  - HTTP Status (401/403) |  - Rate Burst           | - Competitor scrape    |
|  - Target Endpoint URI   |  - Non-Negative Violate | - Precursor probe      |
|  (Never Guesswork)       |  (Heuristic Correlation)| (Requires Review)      |
+-------------------------------------------------------------------------+
```

## 2. Tripartite Classification Rules

### Category A: Confirmed Facts (Green Accent `#22C55E`)
- Directly supported by recorded SQLite telemetry and HTTP network capture.
- Examples:
  - `"Adversary source IP recorded as '198.51.100.22'."`
  - `"Incident flagged by detection rule 'AUTH-001' with severity 'HIGH'."`
  - `"Target endpoint impacted: /api/shop/auth/login."`
  - `"Total telemetry event records captured: 14 event(s)."`
  - `"Observed HTTP response status codes: 401, 403."`

### Category B: Probable Causes (Amber Accent `#F59E0B`)
- Supported by detection signatures, sliding-window thresholds, and pattern heuristics.
- Examples:
  - `"High-velocity credential stuffing or brute-force authentication sequence."`
  - `"SQL injection tautology string submitted in catalog search query parameter."`
  - `"Shopping cart delivery fee arithmetic override causing negative total invariant violation."`
  - `"Administrative stats endpoint accessed without verified role='admin' claim."`

### Category C: AI Hypotheses (Purple Accent `#A78BFA`)
- Analytical interpretations and threat actor intent models generated by heuristic reasoning or LLMs.
- Always labeled with uncertainty language (`"may"`, `"might"`, `"suggests"`).
- Examples:
  - `"Threat actor may be testing credentials harvested from external credential breach prior to targeted exfiltration."`
  - `"Source IP might be an automated proxy scraper attempting inventory reconnaissance."`
  - `"Attack may be a precursor probe to identify backend architectural framework and database engines."`

## 3. Graceful AI Provider Degradation

If an external LLM service is offline, unresponsive, or unconfigured, AutoHeal's RCA engine operates **100% deterministically** using the local detection rule catalog and database telemetry. Zero telemetry is lost, and the remediation workflow continues without interruption.
